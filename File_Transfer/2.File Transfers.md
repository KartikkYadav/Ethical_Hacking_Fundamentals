# File Transfers

A map-of-content for moving files to and from a target across every practical channel — staging payloads and tooling onto a host, and exfiltrating loot back off it. Techniques are grouped by transport, from full protocol servers down to a bare TCP socket or a Base64 paste when nothing else is available. See also **Tunneling-and-Port-Forwarding** for getting a listener reachable across network segments.

> Pick a channel by what the target and its egress filtering actually allow: a web client is almost always present (`HTTP`), `SMB` is common on Windows, `SSH` on Linux; when all of those are blocked, fall back to raw sockets, WebDAV, or a copy-paste transfer.
