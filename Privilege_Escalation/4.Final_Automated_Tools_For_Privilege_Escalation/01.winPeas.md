## 1. Overview
* **Definition**: Windows Privilege Escalation Awesome Script.
* **Project**: Part of the PEASS-ng (Privilege Escalation Awesome Scripts Suite) project.
* **Primary Function**: Local information gathering and automated enumeration tool.
* **Target Audience**: Penetration testers, red teamers, security defenders, and auditors.
* **Objective**: Identify misconfigurations, vulnerabilities, and potential vectors to elevate local user privileges to `Administrator` or `NT AUTHORITY\SYSTEM`.

## 2. Color Coding System
The script utilizes explicit color-coding in console outputs to guide manual analysis:
* **🔴 Red / Red Highlight**: Highly probable privilege escalation vectors or critical misconfigurations requiring immediate attention.
* **🟢 Green**: Indicates active security mechanisms, proper configurations, or hardened states.
* **🔵 Cyan**: Useful system context or general information.

## 3. Enumeration & Inspection Target Categories

### A. System & OS Architecture
* OS version, build info, architecture (x86 vs x64).
* Installed hotfixes and missing security patches.
* Active environment variables and security settings (UAC levels, LSA protection).

### B. User & Token Privileges
* Current user identity, groups, and explicit security identifiers (SIDs).
* Critical token privileges (e.g., `SeImpersonatePrivilege`, `SeBackupPrivilege`, `SeTakeOwnershipPrivilege`).

### C. Services & Permissions
* **Unquoted Service Paths**: Identifies executables lacking quotation marks containing spaces within their directory path.
* **Weak Service Permissions**: Scans for service configurations or binaries modifiable by low-privileged groups (e.g., `BUILTIN\Users`).
* **Registry Controls**: Evaluates misconfigured registry permissions related to core services.

### D. Credentials & Secrets Harvesting
* Cleartext credentials located in files (e.g., `unattend.xml`, `sysprep.inf`, PowerShell history files).
* Protected storage objects (Windows Vault, Credential Manager, DPAPI master keys).
* Registry keys caching secrets (`HKLM\SAM`, `HKLM\SECURITY`, Putty sessions, WinSCP profiles).

### E. Scheduled Tasks & AutoRuns
* Tasks executing under high-privilege context pointing to writeable paths or executable files.
* Auto-run items modifiable by a standard system user.

## 4. Compilation Formats & Execution

### A. Formats Available
* **C# Binary**: Compiled version (`winPEASany.exe`, `winPEASx64.exe`) requiring .NET runtime.
* **PowerShell**: Script module (`winPEAS.ps1`) for memory-only execution vectors.

### B. Common Execution Syntaxes
* **Full Automated Scan**:
  ```cmd
  winPEASany.exe
  ```
* **Log Colorized Output to File**:
  ```cmd
  winPEASany.exe log
  ```
* **Optimized / Rapid Inspection**:
  ```cmd
  winPEASany.exe fast
  ```
* **Targeted Services Audit Only**:
  ```cmd
  winPEASany.exe servicesinfo
  ```

### C. Color Initialization (Windows Command Prompt)
To ensure the console renders ANSI colors correctly before launching:
```cmd
REG ADD HKCU\Console /v VirtualTerminalLevel /t REG_DWORD /d 1
```

## 5. Defensive & OpSec Indicators
* **EDR/AV Footprint**: High detection signature profile; static signatures will trigger instant mitigation alerts inside automated systems (e.g., Windows Defender, Cortex XDR, CrowdStrike).
* **Defensive Application**: Utilized proactively by blue teams to map internal posture states and deploy hardening policies prior to threat deployment.
