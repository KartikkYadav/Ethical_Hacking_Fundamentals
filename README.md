# Ethical_Hacking_Fundamentals

A structured cybersecurity knowledge base containing practical notes, methodologies, commands, tools, and lab references for ethical hacking and penetration testing.

## About

This repository is a personal learning and reference collection focused on hands-on cybersecurity. It brings together organized notes covering offensive security fundamentals, network security, enumeration, Active Directory, file transfer, privilege escalation, tunneling, wireless security, and related topics.

The goal is to maintain clear, practical, and easy-to-reference material for continuous learning, lab practice, and penetration testing.

## Repository Contents

### Active Directory
Notes covering Active Directory concepts, lab setup, enumeration, authentication, and security testing.

### Enumeration Techniques for Penetration Testing
Practical enumeration techniques for discovering services, identifying technologies, gathering information, and mapping attack surfaces.

### File Transfer
Methods, tools, and techniques for transferring files between systems during authorized security assessments and lab environments.

### Information Security
Fundamental information security concepts, terminology, principles, and security practices.

### Networking
Networking fundamentals and security-focused notes covering common protocols, services, proxies, VPNs, and network-based concepts relevant to penetration testing.

### Privilege Escalation
Practical Windows and Linux privilege escalation concepts, enumeration techniques, tools, and technical references.

### Tor & Proxy
Notes covering Tor, proxy technologies, traffic routing, privacy concepts, and related networking techniques.

### Tunneling and Port Forwarding
Practical notes on tunneling, SSH port forwarding, pivoting, and internal network access using tools and techniques such as SSH, Ligolo-ng, and Chisel.

### Wireless Pentesting
Wireless security concepts, tools, and practical notes for authorized wireless security assessments.

## Learning Approach

The notes are organized to support a practical workflow:

**Understand → Enumerate → Test → Validate → Document**

The emphasis is on understanding how techniques work, when they are applicable, and how they can be safely used in authorized labs and penetration testing engagements.

## Usage

This repository is intended as a personal study and technical reference. It can also be useful for cybersecurity students, penetration testers, red team learners, and security enthusiasts looking for organized notes and practical references.

## Responsible Use

All information in this repository is intended for educational purposes and authorized security testing only.

Do not use these techniques against systems, networks, applications, or accounts without explicit permission. Always follow applicable laws, organizational policies, and rules of engagement.
